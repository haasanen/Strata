libgomp.so.1: the GNU OpenMP runtime library, part of the GCC runtime

This engine package carries an unmodified copy of libgomp.so.1 from the build machine. The Inkling-2 engine (strata-inkling)
links OpenMP when the toolchain provides it (engine/src/inkling2/CMakeLists.txt: find_package(OpenMP)), and some Linux systems
(containers, minimal installs) do not have it; binary_deps.py stopped treating libgomp as part of the base OS at 0.2.14, so the
package must carry it (the same way it carries libatomic.so.1).
